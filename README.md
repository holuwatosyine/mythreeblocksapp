# my-three-blocks-app

Website generated by create-three-blocks-starter: rendered in a worker, with shaders precompiled.

## Start here

```bash
npm install
npm run dev
```

Edit `src/scene.ts` first — it is your Three.js scene and hot-reloads without losing its declared `hot` state.

## Project map

| File | Purpose |
|---|---|
| `src/scene.ts` | Your `Experience` class: objects, materials, animation, and scene-local assets. |
| `src/render.worker.ts` | Worker-owned renderer, camera, frame loop, and transactional HMR. |
| `src/main.ts` | DOM input, Lenis, accessibility, and the worker host. |
| `src/assets.ts` | Typed asset manifest. |
| `three-blocks.text.ts` | Text fonts and atlas generation (text template only). |

## Commands

| Command | Purpose |
|---|---|
| `npm run dev` | Start Vite with live worker, shader, text, and HMR status. |
| `npm run lint` | Check correctness and the shipped Three.js-style formatting. |
| `npm run typecheck` | Check strict TypeScript without emitting files. |
| `npm run build` | Build with graceful live shader fallback. |
| `npm run build:strict` | Require fresh precompiled shader receipts. |
| `npm run shaders:capture` | Refresh shader receipts after settling shader edits; also compresses `public/` GLB and HDR assets to meshopt + KTX2. |
| `npm run assets:status` | Re-verify the optimized-asset receipt. |
| `npm run text:generate` | Refresh MSDF atlases after changing glyph coverage. |
| `npm run text:status` | Verify text configuration and generated atlas readiness. |
| `npm run browser:smoke` | Prove worker readiness, first frame, and the stats control in a browser. |
| `npm run status` | Explain and recover worker, shader, asset, or text readiness. |

Precompiled shaders are an optimization cache, not an editing prerequisite. During development, changed TSL code hot-swaps and compiles live; the status reports `shaders live`. Capture once the shader is settled, then use the strict build as the release gate.

Draco and KTX2 runtime files come from the installed Three.js package; this project commits no codec directory. See the [Three Blocks docs](https://threejs-blocks.com/docs) or the [LLM index](https://threejs-blocks.com/llms.txt).
